# Game files

pziOS needs a legitimate copy of Project Zomboid Build 42 (tested with 42.21). Use the in-app importer: choose the Mac game as a `.zip` (Finder's "Compress") or as a folder.
It copies only what the game needs (`projectzomboid.jar`, `media/`, and the standard library files) and ignores Mac executables, libraries and `__MACOSX`.
Free space needed: about 5 GB for a complete copy.
